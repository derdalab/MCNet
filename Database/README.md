
This subdirecoty has been updated since the paper was published and contains a newer version of our database of Fraction Bound values from glycan-protein interactions.

The main Fraction Bound table now lists the protein concentrations in units of nanomolar (instead of µg/mL).  It now contains data from a larger set of CFG arrays as well as select small-molecules from BindingDB.

The protein and molecule identifiers may be looked up in their corresponding auxillary tables to find corresponding amino acid and SMILES strings respsectively.
